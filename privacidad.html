Última actualización: 17 de octubre de 2026

Política de privacidad.

Tharp está diseñado para no necesitar tus datos: los archivos que analizas no salen de tu ordenador.

En resumen

Tharp está diseñado para no necesitar tus datos. Los archivos que analizas se procesan en tu navegador y no se envían a ningún servidor. La web no usa cookies; solo contamos las visitas y el uso de forma anónima y agregada.

Responsable

El responsable del tratamiento es el titular del sitio web tharp.es. Puedes contactar en info@tharp.es para cualquier cuestión sobre privacidad.

Archivos de datos que analizas

Cuando subes un archivo (Excel, CSV, SPSS o JASP) a la aplicación, se lee y se analiza en tu propio equipo mediante el código de la página. El archivo y sus datos no se transmiten a tharp.es ni a ningún tercero, y no se guardan: al cerrar o recargar la pestaña desaparecen. Por tanto, no tratamos los datos de tu investigación.

Navegación por la web

La web no instala cookies ni utiliza almacenamiento local ni píxeles de seguimiento. Las fuentes tipográficas y las librerías se sirven desde el propio dominio.

Estadísticas de uso. Para saber cuántas personas usan Tharp y qué funciones son útiles, usamos Umami (Umami Software, servidores en la Unión Europea), una herramienta de analítica sin cookies que no recoge datos personales ni permite identificar a nadie: registra de forma agregada las páginas visitadas, el país, el tipo de dispositivo y navegador, la web de procedencia y algunos usos de la aplicación (por ejemplo, el formato de archivo cargado —Excel, CSV, SPSS…—, el tipo de prueba ejecutada, el tipo de cálculo de potencia, que se ha descargado un informe o que se ha copiado la cita de Tharp) y qué botones de la portada se pulsan (por ejemplo, «Ver un análisis de ejemplo»). Nunca registra el contenido de tus archivos, los nombres de tus variables ni tus resultados. La base jurídica es nuestro interés legítimo en conocer el uso agregado del servicio para mejorarlo.

La web está alojada en GitHub Pages (GitHub, Inc.). Como cualquier servidor web, GitHub puede registrar datos técnicos de la conexión, como la dirección IP, para garantizar la seguridad y el funcionamiento del servicio. Puedes consultar la declaración de privacidad de GitHub.

Si nos escribes

Si nos envías un correo electrónico (por ejemplo, para participar en el programa piloto), usaremos tu dirección y la información que nos facilites únicamente para responderte y, si lo pides, para contactarte sobre el programa piloto. La base jurídica es tu consentimiento al escribirnos. Conservaremos los mensajes mientras dure la conversación o el programa piloto y después los eliminaremos. No cedemos estos datos a terceros, salvo obligación legal; el correo se gestiona mediante nuestro proveedor de correo electrónico.

Tus derechos

Puedes ejercer tus derechos de acceso, rectificación, supresión, oposición, limitación del tratamiento y portabilidad escribiendo a info@tharp.es. Si consideras que no hemos atendido correctamente tu solicitud, puedes presentar una reclamación ante la Agencia Española de Protección de Datos (aepd.es).

Cambios

Si cambiamos la forma en que funciona Tharp (por ejemplo, si en el futuro hubiera cuentas de usuario), actualizaremos esta política antes de aplicar el cambio.
